Master Theorem & Recurrences

MergeSort Recurrence:
T(n) = 2 T(n / 2) + \Theta(n)

By Master Theorem Case 2: \(a = 2, b = 2, f(n) = \Theta(n)\). Solution: \(\Theta(n \log n)\).

QuickSort Partitioning Recurrence:
T(n) = T(k) + T(n - k - 1) + \Theta(n)

Best Case (\(k = n/2\)): \(T(n) = 2T(n/2) + \Theta(n) \implies O(n \log n)\)

Worst Case (\(k = 0\)): \(T(n) = T(n-1) + \Theta(n) \implies O(n^2)\)

Greedy Graph Paradigms

Kruskal's MST sorts all graph edges by weight using Quick/Heap Sort, then uses Disjoint Set Union (DSU) with Path Compression to build the MST without cycles.

Prim's MST grows a single tree by repeatedly picking the minimum-weight edge connecting the tree to an unvisited vertex using a Min-Priority Queue.

Dijkstra's Shortest Path computes shortest paths from a single source by greedily relaxing edges \(d[u] + w(u,v) < d[v]\).
